¡Correo listo! ✉

El mensaje del correo se escribe una sola vez, pero llega con los datos de cada venta. Eso se logra con las piezas que van entre << >>.

1

Dónde se escribe

En el panel del correo está el campo Email Body. Al tocarlo se abre la ventana Template Assistant; ahí escribimos el mensaje y tocamos el botón Save.

2

Qué es <<[ ]>>

Lo que va entre << >> no se envía tal cual: la app lo cambia por el dato de esa venta. Entre [ ] va el nombre de una columna de la tabla Ventas, escrito igual que en la tabla.

3

Cada pieza

<<[producto]>> → Cuaderno
<<[cantidad]>> → 3
<<[total]>> → $7,500.00
<<[envio]>> → Gratis

4

El resultado

Si se venden 3 cuadernos, al dueño le llega: Se vendió Cuaderno x 3. Total: $7,500.00. Envío: Gratis. Con la siguiente venta, el mismo mensaje llega con los datos nuevos.
