2.1 · Excel: filtros y tablas dinámicas

De las hojas de cálculo al análisis de la información: conceptos, herramientas y funcionamiento de Excel. Las secciones se desarrollan progresivamente desde la interfaz hasta la interpretación de tablas dinámicas.

2.1.1 Excel: qué es y para qué sirve

Microsoft Excel es una aplicación de hojas de cálculo que organiza información en una cuadrícula de filas y columnas. Además de almacenar datos, permite realizar cálculos, buscar registros, compararlos, representarlos y producir resúmenes.

Se utiliza para gestionar inventarios, presupuestos, calificaciones, encuestas y registros de procesos. En una problemática escolar, por ejemplo, permite organizar las llegadas y analizar si los retrasos se concentran en determinados cursos o días.

Excel almacena cada dato en una celda. Las fórmulas trabajan con esos datos y las herramientas de análisis los ordenan, seleccionan o resumen. Un mismo conjunto de datos puede responder distintas preguntas sin volver a registrarlo.

Un libro es el archivo completo; normalmente se guarda como .xlsx. Contiene una o varias hojas. El formato .csv permite intercambiar datos tabulares, pero no conserva elementos como varias hojas, fórmulas o formatos de Excel.

2.1.2 Acceso a Excel y reconocimiento de su interfaz

Excel se puede utilizar como aplicación instalada en un computador o desde el navegador, si se dispone de acceso a Microsoft 365. Al iniciar, ofrece opciones para abrir libros existentes o crear un libro en blanco.

En Windows se encuentra desde Inicio, buscando «Excel». En la versión web se accede desde Microsoft 365, con una cuenta que tenga acceso. En ambos casos, la opción Libro en blanco abre una cuadrícula nueva.

2.1.3 Estructura de una hoja de cálculo

La hoja se compone de columnas identificadas por letras y filas identificadas por números. Su intersección forma una celda, como C4. Varias celdas seleccionadas forman un rango, como A1:D10.

ConceptoDescripciónEjemplo
FilaConjunto horizontal de celdas.La fila 2 representa una llegada.
ColumnaConjunto vertical de celdas.La columna B contiene cursos.
Celda activaCelda seleccionada en la que se escribe o edita.B2.
RangoGrupo de celdas definido por sus extremos.A1:D10.

Texto: nombres, cursos y categorías. Números: edades, cantidades y minutos de retardo. Fechas y horas: valores que Excel puede reconocer y utilizar en operaciones. Valores lógicos: VERDADERO/FALSO. Una fórmula comienza con = y produce un resultado.

El formato cambia la presentación de un dato, no necesariamente su valor: una hora puede mostrarse como 07:15 y seguir siendo un valor de tiempo válido.

Una referencia relativa como A2 se ajusta al copiar una fórmula; una absoluta como $A$2 mantiene fija columna y fila; una mixta fija solo una de ellas, como $A2 o A$2. Estas referencias permiten reutilizar cálculos sin reescribirlos.

2.1.4 Registro y organización de los datos

Antes de analizar información, debe existir una base de datos tabular coherente. En Excel esto significa que cada columna representa una variable, cada fila representa un registro y la primera fila contiene nombres claros para los campos.

La primera fila es el encabezado. Cada fila siguiente corresponde a una observación y cada columna conserva un mismo tipo de información.

Formato de celdas: facilita leer fechas, horas y números. Formato como tabla (Inicio → Dar formato como tabla, o Insertar → Tabla): convierte un rango organizado en una tabla que facilita la expansión y el uso de encabezados y filtros. Ordenar: cambia el orden de los registros (por fecha, nombre, cantidad, etc.) sin eliminar datos.

Validación de datos (Datos → Validación de datos): define qué valores se admiten en determinadas celdas; por ejemplo, una lista de cursos permitidos.

La coherencia importa más que el aspecto visual. Es necesario mantener nombres consistentes (8A y 8-A podrían tratarse como categorías diferentes), fechas válidas y una sola información por celda. Las celdas combinadas, subtotales intercalados y encabezados repetidos dificultan los filtros y las tablas dinámicas.

2.1.5 Fórmulas y funciones para procesar información

Una fórmula es una expresión que calcula un resultado a partir de valores o referencias; empieza con =. Una función es una operación predefinida que recibe argumentos, como =SUMA(D2:D20). El separador de argumentos puede variar entre punto y coma y coma según la configuración de Excel.

Los operadores más comunes son + (suma), - (resta), * (multiplicación) y / (división). Por ejemplo, =D2-D3 obtiene la diferencia entre dos cantidades. Una fórmula que utiliza referencias se actualiza si cambian los datos de origen.

FunciónQué devuelveEjemplo
SUMATotal de valores numéricos.=SUMA(D2:D20)
PROMEDIOMedia aritmética.=PROMEDIO(D2:D20)
MAX / MINMayor / menor valor.=MAX(D2:D20)
CONTARCeldas con números.=CONTAR(D2:D20)
CONTARACeldas no vacías.=CONTARA(B2:B20)

=SI(D2>0;"Tarde";"Puntual") clasifica una llegada según los minutos de retraso. =CONTAR.SI(E2:E20;"Tarde") cuenta registros que cumplen una condición. =SUMAR.SI(B2:B20;"8A";D2:D20) suma los minutos de retraso correspondientes al curso 8A.

Estas funciones transforman registros en información útil; más adelante, una tabla dinámica permitirá obtener agrupaciones semejantes sin construir una fórmula para cada curso.

2.1.6 Ordenación y filtros: consultar registros

Ordenar reorganiza los registros según un criterio: alfabético, numérico o cronológico. Filtrar muestra únicamente los registros que cumplen condiciones; los demás permanecen en la base de datos, pero se ocultan temporalmente.

HerramientaPregunta que respondeResultado
Ordenar¿Cuáles son los retrasos más altos?Coloca primero los valores mayores.
Filtrar¿Qué registros corresponden al curso 8A?Muestra únicamente las filas de 8A.
Filtrar por varias columnas¿Qué llegadas tarde tuvo 8A en septiembre?Combina condiciones en distintas columnas.

Por texto: igual a, contiene o comienza por. Por número: mayor que, menor que o entre dos valores. Por fecha: días, meses o intervalos. Por color: según el formato aplicado a las celdas. Los menús disponibles dependen del tipo de dato que reconoce Excel en la columna.

El comando Datos → Filtro activa menús desplegables en los encabezados del rango. En cada encabezado se pueden seleccionar valores o aplicar condiciones. Si los datos están convertidos en una Tabla de Excel, los controles de filtrado suelen estar disponibles en sus encabezados. Borrar filtro restaura la visualización de los registros.

Filtrar no significa borrar. Los registros ocultos siguen formando parte de la base y pueden volver a mostrarse.
2.1.7 Tablas dinámicas: resumir y comparar datos

Una tabla dinámica es una herramienta para resumir datos por categorías sin alterar los registros originales. Permite calcular totales, recuentos, promedios y comparaciones, cambiando la disposición de las variables para responder distintas preguntas.

ÁreaFunciónEjemplo
FilasDefine las categorías que aparecen verticalmente.Curso.
ColumnasPermite comparar categorías horizontalmente.Estado de llegada.
ValoresCalcula recuentos, sumas, promedios, etc.Recuento de registros.
FiltrosLimita el resumen a una parte de la información.Mes.

Un mismo campo puede servir en distintas áreas según la pregunta que se quiera responder.

En Excel se selecciona una celda de la base organizada y se usa Insertar → Tabla dinámica. Se confirma el origen de los datos y se elige dónde ubicar el resumen. En la lista de campos, se distribuyen las variables entre Filas, Columnas, Valores y Filtros. En Valores puede cambiarse la operación a Recuento, Suma o Promedio, según el tipo de dato y el análisis requerido.

Cuando cambian los datos de origen, puede ser necesario utilizar Actualizar para reflejar las modificaciones en el resumen. Si se agregan registros, el origen también debe incluirlos; usar una Tabla de Excel facilita ese mantenimiento.

Supongamos que la tabla dinámica agrupa por curso y cuenta los registros clasificados como «Tarde»:

En este ejemplo ilustrativo, 8A tiene más registros de llegadas tarde. Para comparar tasas entre cursos se necesitaría, además, conocer cuántas oportunidades de llegada hubo en cada curso: el recuento por sí solo no establece qué grupo presenta proporcionalmente más impuntualidad.

2.1.8 De los resultados al análisis de una problemática

Excel permite avanzar de datos (registros individuales) a información (totales y comparaciones), y de ahí al análisis (interpretación de patrones y posibles decisiones). Filtrar responde preguntas sobre casos específicos; una tabla dinámica responde preguntas sobre conjuntos de registros.

Datos registrados→Datos organizados→Filtros→Tablas dinámicas→Interpretación

Primero se define qué se desea conocer; después se identifica la variable adecuada, se aplica la herramienta y se examina el resultado. La herramienta se elige por la pregunta, no al revés.

Un número aislado no explica las causas de un fenómeno. Si una tabla dinámica muestra 24 registros de llegadas tarde, el resultado describe una frecuencia. Comparar por curso y por día puede revelar concentraciones; establecer por qué ocurren requiere datos adicionales o fuentes complementarias.

Los análisis dependen de la calidad y cobertura de la base de datos. Registros duplicados, fechas incompletas o categorías inconsistentes alteran los resúmenes. Las tablas dinámicas ayudan a reconocer patrones descriptivos, pero no prueban por sí mismas relaciones de causa y efecto.
