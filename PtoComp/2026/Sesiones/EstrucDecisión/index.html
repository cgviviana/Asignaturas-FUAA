Estructuras de decisión

Aprende a construir algoritmos que eligen qué hacer a partir de una condición.

01 · COMPRENDE

¿Cómo toma decisiones un algoritmo?

Una condición es una pregunta que solo puede responderse con Verdadero o Falso. Según el resultado, el programa elige una instrucción.

Ejemplo: ¿La nota es mayor o igual a 3? Si lo es, muestra «Aprobó»; en caso contrario, «Por mejorar».
En PSeInt se usan comparaciones como >, <, >=, <=, = y <>.
Leer nota→¿nota >= 3?V →AprobóF →Por mejorar
02 · DECISIÓN SIMPLE

Si ... Entonces ... FinSi

Se ejecuta una acción solo cuando la condición es verdadera. Si es falsa, el algoritmo continúa después de FinSi.

Si una compra supera $100.000, se anuncia un beneficio.

Prueba mental: con un total de $120.000 aparece el mensaje; con $80.000 se omite.

Proceso Beneficio
  Definir total Como Real
  Escribir "Valor de compra:"
  Leer total
  Si total > 100000 Entonces
    Escribir "Aplica beneficio"
  FinSi
FinProceso
03 · DECISIÓN DOBLE

Si ... Entonces ... SiNo

Permite elegir entre dos caminos excluyentes: uno cuando la condición es verdadera y otro cuando es falsa.

Para una nota de 3.0, la condición nota >= 3 es verdadera: el estudiante aprueba.
La indentación ayuda a reconocer las instrucciones que pertenecen a cada camino.
Proceso Resultado
  Definir nota Como Real
  Escribir "Digite la nota:"
  Leer nota
  Si nota >= 3 Entonces
    Escribir "Aprobó"
  SiNo
    Escribir "Por mejorar"
  FinSi
FinProceso
04 · VARIAS DECISIONES

Decisiones anidadas

Cuando hay más de dos resultados, podemos colocar una segunda decisión dentro de SiNo.

Nota de 4.5 a 5: alto; de 3 a menos de 4.5: aprobado; menor de 3: por mejorar.

Se consulta primero el límite mayor; solamente si no se cumple se pregunta por el siguiente.

Proceso NivelNota
  Definir nota Como Real
  Leer nota
  Si nota >= 4.5 Entonces
    Escribir "Alto"
  SiNo
    Si nota >= 3 Entonces
      Escribir "Aprobado"
    SiNo
      Escribir "Por mejorar"
    FinSi
  FinSi
FinProceso
