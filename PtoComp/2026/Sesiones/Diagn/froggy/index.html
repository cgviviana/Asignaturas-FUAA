En un proceso se presentan errores frecuentes y el equipo necesita ordenar sus posibles causas en categorías como personas, método, datos, herramientas, entorno y control. ¿Qué herramienta debe utilizar?

Correcto. El diagrama de Ishikawa permite organizar las posibles causas del problema en grupos para analizarlas de manera estructurada.
No. Cuando se necesita identificar y agrupar las posibles causas de un problema, la herramienta adecuada es el diagrama de Ishikawa.

En un árbol de problemas, ¿cómo deben ubicarse correctamente los elementos del diagnóstico?

Correcto. El árbol relaciona causas, problema central y efectos: raíces = causas, tronco = problema central y ramas = efectos.
No. Recuerda la lógica del árbol: las raíces representan las causas, el tronco el problema central y las ramas sus efectos.

El equipo quiere mostrar cómo se realiza hoy un proceso, incluyendo acciones, decisiones, datos utilizados y responsables. ¿Qué debe construir?

Correcto. El flujo actual representa la secuencia real del proceso y permite ubicar acciones, decisiones, datos y responsables.
No. Para representar cómo ocurre realmente el proceso hoy se utiliza el flujo actual, antes de diseñar cualquier automatización.

Un grupo ya seleccionó una situación problemática. ¿Cuál es la acción correcta durante la etapa de diagnóstico?

Correcto. En el diagnóstico todavía no se diseña la solución: primero se comprende qué ocurre actualmente y por qué ocurre.
No. Diagnosticar significa comprender el proceso existente antes de proponer la automatización o seleccionar una solución.

Reto 5 de 5

¿Qué secuencia integra correctamente las tres herramientas para obtener una visión completa del diagnóstico?

Correcto. Las tres herramientas se complementan: Ishikawa organiza causas, el árbol relaciona causas y efectos, y el flujo muestra dónde aparecen las dificultades en el proceso real.
No. El diagnóstico parte del proceso actual: primero se analizan las causas, luego su relación con el problema y sus efectos, y finalmente se representa la secuencia real.
