Cuando una regla depende de otra

Las páginas web, las aplicaciones y los procesos empresariales toman decisiones según la información que reciben. En este laboratorio observarás cómo funcionan esas reglas y construirás tus propias soluciones en PSeInt.

¿Qué es una decisión anidada?

Es una decisión dentro de otra. Por ejemplo, primero verificar si alguien tiene una reserva y, solo si la tiene, comprobar si aún está vigente. No confundas dos comprobaciones consecutivas con una sola condición que usa Y.

Ruta de trabajo: analiza el caso → cambia las entradas → ejecuta → observa la ruta del diagrama → revisa el código → intenta el reto en PSeInt.

Desafíos del laboratorio

En cada caso, escribe primero el análisis de entradas, condiciones y salidas; luego diseña el diagrama y programa la solución. No se entrega el algoritmo resuelto: tú debes construirlo.

Pruebas mínimas: ejecuta cada programa con un caso que cumpla las condiciones, otro que no las cumpla y un caso límite. Compara las salidas y corrige los errores.
