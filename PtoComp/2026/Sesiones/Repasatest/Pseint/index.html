Qué es PSeInt
Tu primer paso para programar
PSeInt es un programa gratuito para aprender a programar. Escribes el algoritmo en pseudocódigo (pasos en español), lo ejecutas y ves el resultado.
Sirve para practicar la lógica antes de pasar a un lenguaje como Python o Java. Te muestra los errores en español y puede dibujar el diagrama de flujo de tu algoritmo.
Algoritmo saludo
  Escribir "Hola mundo"
FinAlgoritmo
Diagrama de Flujo
El dibujo del algoritmo
Cada figura es un tipo de instrucción y las flechas muestran el orden de los pasos. PSeInt lo dibuja solo desde tu pseudocódigo.

Estructura Secuencial
Un paso detrás de otro
Las instrucciones se ejecutan una tras otra, de arriba hacia abajo, sin saltarse ninguna. Es la estructura más simple.
Casi siempre sigue este orden: entrada (Leer) → proceso (calcular) → salida (Escribir).
Algoritmo areaRectangulo
  Definir base, altura, area Como Real
  Escribir "Base:"
  Leer base // entrada
  Escribir "Altura:"
  Leer altura
  area <- base * altura // proceso
  Escribir "El área es: ", area // salida
FinAlgoritmo
Estructura de Decisión
También llamada condicional
El algoritmo hace una pregunta (una condición) y según la respuesta, Verdadero o Falso, toma un camino u otro.
EstructuraCuándo se usa
Si ... FinSiUn solo camino: hace algo solo si se cumple
Si ... SiNoDos caminos: uno si se cumple, otro si no
SegunVarios caminos según el valor de una variable

Estructura Repetitiva
También llamada ciclo o bucle
Repite un grupo de instrucciones varias veces: mientras se cumpla una condición o un número fijo de veces.
EstructuraCuándo se usa
MientrasRepite mientras la condición sea Verdadera. Puede no ejecutarse nunca
RepetirRepite Hasta Que se cumpla la condición. Se ejecuta al menos una vez
